# Ground Truth Findings Directory (`evals/findings/`)

Paste your ground truth findings (generated by ChatGPT or human legal annotations) into this directory.

---

## How to Paste Files So the Script Matches Them

You can organize your files in any of the following 3 ways — the comparison script automatically detects all of them:

### Option 1: One File Per Contract (Recommended)
Save the findings as a JSON file matching the contract filename (or prefix/stem).

**Example:**
- Contract in `test_data/`: `ZtoExpressCaymanInc_20160930_F-1_EX-10.10_9752871_EX-10.10_Transportation Agreement.txt`
- Findings file in `evals/findings/`: `ZtoExpressCaymanInc_20160930_F-1_EX-10.10_9752871_EX-10.10_Transportation Agreement.json`
*(Even `ZtoExpressCaymanInc.json` works!)*

### Option 2: Automatic Content & Quote Matching
If you paste a list of findings into **any** `.json` or `.txt` file in this folder (e.g. `findings.json` or `chatgpt_findings.json`), the script will automatically inspect the `evidence_quote` or `summary` and match each finding to the correct contract in `test_data/`!

### Option 3: Master JSON Map
You can have a single `ground_truth.json` file where keys are contract filenames:
```json
{
  "ZtoExpressCaymanInc_20160930_F-1_EX-10.10_9752871_EX-10.10_Transportation Agreement.txt": [
    {
      "agent_name": "Risk & Liability Counsel",
      "clause_type": "Liability",
      "finding_type": "Uncapped Carrier Liability for Theft and Parcel Loss",
      "summary": "...",
      "evidence_quote": "Party B shall be responsible for all of Party A's economic loss...",
      "severity_score": 9,
      "risk_level": "Critical",
      "confidence": 0.99
    }
  ]
}
```

---

## Tolerates Markdown Code Fences
If you paste directly from ChatGPT including the markdown code fence:
````text
```json
[
  { ... }
]
```
````
The script will automatically strip the backticks and parse the JSON cleanly.

---

## Running the Comparison

Run from root:
```bash
python scripts/compare_findings.py
```
Or via wrapper:
```bash
python evals/compare_findings.py
```
Or on a single contract:
```bash
python scripts/compare_findings.py "evals/test_data/ZtoExpressCaymanInc_20160930_F-1_EX-10.10_9752871_EX-10.10_Transportation Agreement.txt"
```
